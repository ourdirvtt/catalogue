# Catalogue Ourdir

Le catalogue des paquets d'[Ourdir](https://ourdir.fr) : systèmes de jeu, modules, et bientôt thèmes de table, compendiums, packs de cartes, aventures et traductions. On le parcourt et on installe depuis la page **Catalogue** de l'appli.

Tout est signé : l'appli vérifie chaque fichier avant de l'installer, quel que soit l'endroit d'où il vient.

## Les niveaux

| Niveau | Signifie |
|---|---|
| **Ourdir** | fait par Ourdir |
| **Officiel** | publié par l'ayant droit, ou sous sa licence |
| **Validé** | relu par Ourdir (la version pour un module ; le créateur pour un contenu sans code) |
| **Communautaire** | contrôlé par machine, pas relu par un humain |
